# MindTrace — Doomscrolling Detection & Behavioural Analysis (Frontend Prototype)

MindTrace is a college research prototype UI for analysing smartphone behavioural
events and surfacing patterns that may warrant closer inspection. It deliberately
**does not** label all scrolling or all social-media usage as doomscrolling.

## Stack

- React + Vite
- Tailwind CSS
- Recharts
- Lucide React icons
- React Router

## Install & Run

```bash
npm install
npm run dev
